# Studying for a Software Engineer Technical Interview

This repo includes code samples and resources as a companion to the [How to Study for a Software Engineer’s Technical Screening and Interview for a Job](https://www.ryanchapin.com/how-to-learn-software-engineering-and-interview-for-a-job/) study guide.

It is a work-in-progress, so there are some parts that are not yet completely fleshed out.

## Use a Text Editor
Do not use an IDE while studying.  Using a text editor will force you to memorize the exact syntax in the coding language with which you are studying.  As a result, I highly recommend going through these exercises using ONLY vim or other text editor.
